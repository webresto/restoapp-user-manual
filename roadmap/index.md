# Обзор документации и план работ (Roadmap)

Этот файл определяет план документирования админ-панели `restoapp.com`.

## Цель проекта
Создать исчерпывающее, визуально поддерживаемое руководство по интерфейсу администратора для использования людьми-закупщиками, управляющими и AI-агентами.

## План и статус
- [x] Первоначальный захват экрана логина/дашборда.
- [x] Документирование разделов:
    - [x] `catalog/` (Дерево категорий, редактирование блюд, каталоги).
    - [x] `stock_manager/` (Стоп-листы, режимы).
    - [x] `orders/` (Только режим Стопка/Pile).
    - [x] `system/` (Права пользователей, Группы, Настройки).
    - [x] `platform/` (Обзор платежей, зон и др.).
