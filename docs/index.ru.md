# 📖 Руководство пользователя RestoApp

Добро пожаловать в официальное руководство по административной панели RestoApp. Здесь собраны инструкции по управлению рестораном, меню, складом, заказами и другими возможностями системы.

## Что внутри
Руководство описывает все разделы административной панели — от каталога блюд и склада до заказов, каналов продаж, маркетинга, уведомлений и системных настроек. Каждая страница содержит скриншоты интерфейса с пояснениями ключевых функций.

## Как пользоваться руководством
Все разделы доступны в боковой панели навигации слева (группа **«Разделы системы»**). Выберите нужный раздел, чтобы открыть подробную инструкцию.

- Для поиска по всему руководству используйте строку поиска вверху страницы.
- Язык руководства (English / Русский) переключается в верхней части страницы.
