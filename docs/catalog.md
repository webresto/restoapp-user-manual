# Dish Catalog (Tree View)

The **Catalog** section is used for managing the product range, prices, and dish information.

## Navigation
1. Open the Admin Panel.
2. Select **Catalog** from the left menu.
3. You will see a hierarchical tree showing root folders like `restoapp.org`, `Add-ons`, `Sides`, etc.

## Key Features
- **Tree View**: Manage categories and subcategories by dragging and dropping.
- **Product Editing**: Change names, descriptions, and prices.
- **Visibility**: Toggle dishes on and off for the customer app.
