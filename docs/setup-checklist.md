# ✅ Setup Checklist

The **Setup Checklist** guides you through the steps needed to get a new store ready for
business. It checks your configuration automatically and shows what is still missing.

Path: **Sidebar → System → Setup checklist**

The header shows your overall progress. When everything required is done you'll see a
**Ready to go** badge; otherwise it shows how many **required steps** are left. Three chips
summarise progress by importance:

| Chip | Meaning |
|------|---------|
| **Required** | Steps the store cannot operate without |
| **Recommended** | Strongly advised for a good setup |
| **Optional** | Nice-to-have improvements |

Use **Refresh** to re-run the checks, and **Show hidden** to reveal items you've hidden.

## Checklist items

Items are grouped by area. Each item shows:

- A **title** and short **description**.
- A **progress** indicator (e.g. *3 of 5*) for multi-part steps.
- A **Go to setup** link that jumps straight to the screen where you complete the step.

If a check cannot run it shows **Could not check** — try **Refresh**.

## Hiding and snoozing

For items you don't need right now:

- **Hide** removes the item from the list (bring it back with **Show hidden** → **Restore**).
- **Snooze for 7 days** temporarily hides it; it reappears automatically after a week.

> [!TIP]
> Work top-to-bottom through the **Required** group first — those steps unblock the store.
> Treat **Recommended** and **Optional** as polish you can return to later.
