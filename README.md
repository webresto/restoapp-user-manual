# 📖 Руководство пользователя админ-панели RestoApp




Добро пожаловать в руководство пользователя по управлению платформой `restoapp.org`. В этой документации собраны инструкции по основным модулям администрирования ресторана.

## 📑 Оглавление

1.  **[🥗 Управление каталогом и блюдами](docs/catalog.md)**
    *   Навигация через дерево категорий.
    *   Использование контекстного меню.
    *   Редактирование характеристик блюд.

2.  **[📋 Управление заказами](docs/orders.md)**
    *   Особенности режима «Стопка» (Stack).
    *   Жизненный цикл заказа (статусы).
    *   Работа со списком заказов.

3.  **[📦 Менеджер склада (Стоп-листы)](docs/stock-manager.md)**
    *   Управление доступностью блюд в реальном времени.
    *   Настройка лимитов (Баланс).
    *   Просмотр списка отсутствующих позиций.

4.  **[👥 Управление пользователями и правами (Доступ)](docs/users-and-groups.md)**
    *   Управление административными аккаунтами.
    *   Настройка групп доступа и матрицы разрешений.
    *   Скриншоты и действия с учетными записями.

5.  **[🌐 Обзор вкладки Платформа (Platform)](docs/platform-overview.md)**
    *   Настройка способов оплаты.
    *   География доставки: зоны и улицы.
    *   Работа с сырыми данными моделей ( Origin Products/Groups).

6.  **[🛠️ Технический раздел: Система (System)](docs/system-technical.md)**
    *   Журнал административных действий (LogAP).
    *   Глобальные настройки и системные константы.
