# Stock Manager

The **Stock Manager** is responsible for managing item availability and stop-lists.

## Features
- **Stop-lists**: Quickly disable dishes that are out of stock.
- **Sync**: Automatically sync balances from iiko/RMS.
- **Modes**:
    - **Show/Hide**: Control visibility in the app.
    - **Enable/Disable**: Control whether it can be ordered.
    - **Quantity**: Set exact stock numbers.

## Adding to Stop-list
1. Navigate to Stock Manager.
2. Search for the dish.
3. Click the toggle to move it to the "Stop-list" section.
